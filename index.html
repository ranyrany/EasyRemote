STEP 01 · 다운로드

사용 중인 컴퓨터를 선택하세요.

휴대폰이 아닌, 지원받을 컴퓨터에서 다운로드해 주세요.

Windows

일반적인 Windows PC · Intel / AMD 64비트

Windows 다운로드 ↗ (공식 최신 릴리스, 새 탭)공식 페이지에서 x86-64 행 → Windows 열의 EXE를 선택하세요.
Windows ARM PC는 AArch64 (ARM64) 행의 EXE를 선택하세요.
⌘

Mac

Mac의 칩 종류에 맞는 파일을 선택하세요.

Apple Silicon 다운로드 ↗ (공식 최신 릴리스, 새 탭)Intel Mac 다운로드 ↗ (공식 최신 릴리스, 새 탭)Apple Silicon (M 시리즈): AArch64 (ARM64) 행 → Mac 열
Intel Mac: x86-64 행 → Mac 열
해당 Download를 눌러 .dmg 파일을 받으세요.
ⓘ

모든 다운로드 버튼은 공식 최신 릴리스 페이지를 새 탭으로 엽니다. 파일은 그 페이지에서 직접 선택해 주세요.
Mac 칩 확인: 왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 ‘칩’이 Apple M 시리즈이면 Apple Silicon, ‘프로세서’가 Intel이면 Intel Mac을 선택하세요.
파일 목록(Assets)에서 고른다면 Apple Silicon은 aarch64.dmg, Intel Mac은 x86_64.dmg로 끝나는 파일을 찾으세요.
RustDesk 공식 최신 다운로드 페이지 ↗ (새 탭)

STEP 02 · 실행 및 연결

처음이어도 괜찮아요.
하나씩 따라 해보세요.

Windows에서 실행하기

다운로드 폴더에서 rustdesk로 시작하는 .exe 파일을 더블클릭하세요. 실행 후 RustDesk 창을 열어 두세요. 설치나 관리자 권한이 필요한 작업은 담당자의 설명을 듣고 진행하세요.

Mac에서 실행하기

.dmg 파일을 열고 RustDesk를 응용 프로그램 폴더로 옮긴 뒤 실행하세요. 시스템 설정 → 개인정보 보호 및 보안에서 RustDesk의 화면 기록(화면 및 시스템 오디오 녹음)과 손쉬운 사용을 허용하세요. 키보드·마우스가 작동하지 않으면 입력 모니터링 권한도 확인하세요. 변경 후 앱을 다시 실행해야 할 수 있습니다.

Mac 공식 설치·권한 안내 ↗ (새 탭, 영문)
1

내 ID를 확인하세요

RustDesk 첫 화면의 ‘내 데스크톱’ 영역에서 ID를 찾으세요. 버전이나 언어 설정에 따라 이름이 조금 다를 수 있어요.

2

일회용 비밀번호를 확인하세요

ID 아래의 비밀번호를 확인하세요. 가려져 있으면 표시 아이콘을 눌러 확인하고, 표시되지 않으면 비밀번호 옆 메뉴나 설정 → 보안에서 일회용(임의) 비밀번호 사용 여부를 확인하세요. 영구 비밀번호를 새로 만들 필요는 없어요.

3

담당자에게 전달하고 연결을 확인하세요

상담 중인 신뢰할 수 있는 담당자에게만 ID와 일회용 비밀번호를 알려주세요. 연결 요청 창이 나오면 상대를 확인하고 수락하세요. 연결 후에는 화면을 함께 보며 안내를 받으세요.

비밀번호는 이 홈페이지에 입력하지 않아요.

이 페이지에는 ID·비밀번호 입력란이 없습니다. 공유 전에 개인 문서와 금융 화면을 닫고, 모르는 사람의 연결 요청은 거절하세요.

STEP 03 · 지원 종료

지원이 끝나면
연결을 종료하세요.

원할 때 언제든 직접 연결을 끊을 수 있어요.

  1. 현재 원격 연결 끊기

    내 컴퓨터의 RustDesk 연결 알림 또는 세션 창에서 ‘연결 끊기’ / ‘종료’를 누르세요.

  2. 프로그램까지 완전히 종료하기

    창의 X 버튼은 트레이에 남을 수 있어요. Windows 작업 표시줄의 숨겨진 아이콘(∧) 또는 Mac 메뉴 막대에서 RustDesk 아이콘을 찾아 종료 / Quit를 선택하세요.

  3. 다음 지원 전 비밀번호 새로 확인하기

    일회용 비밀번호 옆 새로고침·변경 메뉴로 재생성하세요. 설치된 서비스나 영구 비밀번호를 설정했다면 완전한 접근 중지를 위해 설정의 서비스 중지 또는 앱 제거도 담당자에게 안내받으세요.

도움이 필요하신가요?

자주 묻는 질문

다운로드 버튼을 눌렀는데 파일이 안 보여요.

버튼은 파일을 바로 저장하는 대신 공식 최신 릴리스 페이지 (새 탭)를 엽니다. 해당 페이지에서 위 안내에 따라 운영체제와 칩에 맞는 파일을 선택하세요. 파일을 선택한 뒤에는 브라우저의 다운로드 목록 또는 컴퓨터의 ‘다운로드’ 폴더를 확인하세요. 보안 경고가 나오면 임의로 보호 기능을 끄지 말고 담당자에게 화면 내용을 알려주세요.

ID가 안 보이거나 연결 준비가 되지 않아요.

인터넷 연결을 확인하고 RustDesk를 다시 실행해 보세요. 회사·기관 네트워크라면 연결이 제한될 수 있으니 담당자에게 상태 메시지를 알려주세요. 이 홈페이지를 열어 두는 것만으로 원격지원이 연결되지는 않습니다.

Mac에서 화면이 안 보이거나 마우스가 움직이지 않아요.

위의 ‘Mac 안내’에서 화면 기록 및 손쉬운 사용 권한을 확인하세요. 필요하면 입력 모니터링도 허용하고 RustDesk를 다시 실행하세요. macOS 버전에 따라 설정 이름이 다를 수 있습니다.

회원가입이나 홈페이지에 정보 입력이 필요한가요?

이 안내 홈페이지에서는 회원가입이나 정보 입력이 필요하지 않습니다. 다운로드와 실제 원격 연결은 외부 서비스인 RustDesk에서 이루어지며 해당 서비스의 정책이 적용됩니다.

필요할 때 연결하고, 끝나면 안전하게 종료하세요.

RustDesk 사용을 돕는 독립적인 안내 페이지입니다. RustDesk 공식 사이트가 아닙니다.
이 홈페이지는 개인정보를 입력받거나 저장하지 않습니다.
